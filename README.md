# tm-amazon-list-size

Tampermonkey script to allow bigger scripts on amazon.de

## Run a common local Node.js dev server

1. Install Node.js (18+).
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local server:
   ```bash
   npm run start
   ```
4. Install or update the script in Tampermonkey from:
   `http://localhost:9090/src/amazon-list-size.user.js`
